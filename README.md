# Project-Hyperscale

Project HyperScale is a create based industrial progression pack where every age introduces new production constraints, science requirements, and logistical problems which forces the player to build increasingly complex factories to sustain large-scale progress—until they manufacture the means to escape the universe itself.

Our working modlist can be [here](https://github.com/KSAW00/Project-Hyperscale/blob/main/Modlist.md)
